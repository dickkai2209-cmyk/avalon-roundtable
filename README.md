# 卡美洛密令 · Camelot Cipher

免安裝、用手機瀏覽器就可以玩的《阿瓦隆》(The Resistance: Avalon) 多人遊戲。不需要微信。

- 建立房間 → 4 位房間號；同枱朋友掃二維碼 / 開邀請連結 / 輸入房間號入座（5–10 人）
- 圓桌座位圖（房主可點兩人交換座位）、入場特效
- 角色：梅林、刺客（必選）、派西維爾、莫甘娜、莫德雷德、奧伯倫；擴展：湖中仙女
- 原創角色立繪 + 卡背，翻牌揭曉身份（遮住螢幕提示），可解鎖角色皮膚
- 完整流程：隊長輪替、組隊、同時公開投票（翻牌動畫）、5 次否決、秘密任務卡（洗牌翻開）、7 人以上第 4 輪需 2 張失敗、刺殺梅林
- 結算：全員身份、MVP / 亞軍計分、精彩時刻、組隊投票全記錄、戰報海報
- 歷史記錄、對局詳情、數據統計（好壞陣營勝負、各角色勝率）
- 互動規則頁：概覽 / 陣營 / 誰知道誰 / 一輪點行動畫 / 任務 / 勝負 / 思路 / 擴展

## 本地運行

```bash
npm install
npm start          # http://localhost:3000
npm test           # 以 socket 客戶端模擬多人完整對局（需先啟動伺服器，可用 URL=... 指定）
```

技術：Node.js + Express + Socket.IO；房間存於記憶體，歷史 / 統計存於 `data/db.json`（`DATA_DIR` 可改路徑）。
