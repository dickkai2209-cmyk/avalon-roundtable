# 圓桌密令 · 阿瓦隆

免安裝、用手機瀏覽器就可以玩的《阿瓦隆》(The Resistance: Avalon) 多人助手。不需要微信。

- 建立房間 → 4 位房間號，同枱朋友掃二維碼或輸入房間號加入（5–10 人）
- 房主可選角色：梅林、刺客（必選）、派西維爾、莫甘娜、莫德雷德、奧伯倫
- 每人手機私下顯示身份及應知資訊
- 完整流程：隊長輪替、組隊、同時公開投票、5 次否決、秘密任務卡、7 人以上第 4 輪需 2 張失敗、刺殺梅林
- 任務軌、投票記錄、結算公開所有身份、歷史記錄、各角色勝率

## 本地運行

```bash
npm install
npm start          # http://localhost:3000
npm test           # 用 socket 客戶端模擬多人完整對局（需先啟動伺服器）
```

技術：Node.js + Express + Socket.IO，房間存於記憶體，歷史/統計存於 `data/db.json`（可用 `DATA_DIR` 指定）。
