# 旺角Avalon

by Amigosparty

免安裝、用手機瀏覽器就可以玩的《阿瓦隆》(The Resistance: Avalon) 多人遊戲。不需要微信。深海軍藍 + 金色、木質圓桌與羊皮紙規則的原創介面。

- 訪客或帳號（用戶名 + 密碼 / 4–6 位 PIN）；換手機登入可還原暱稱、頭像、歷史與統計
- 建立房間 → 4 位房間號；掃二維碼 / 邀請連結入座（5–12 人）
- 房主選人數，自動套用標準角色配置，並以「藍方 / 紅方」摘要顯示；進階角色可選
- 圓桌一開始就顯示全部空位，點空位就座；入場特效、動物頭像與掛件
- 角色：梅林、派西維爾、忠臣、刺客、莫甘娜、莫德雷德、奧伯倫、蘭斯洛特
- 擴展（房間內即時同步）：湖中仙女（8 人以上預設開）、王者之劍、蘭斯洛特（11 人以上預設開）、回避卡
- 原創角色立繪 + 卡背，翻牌揭曉身份（遮住螢幕提示）
- 完整流程：隊長輪替、組隊、同時公開投票、5 次否決、秘密任務卡、7 人以上第 4 輪需 2 張失敗、刺殺梅林
- 結算：全員身份、MVP / 亞軍計分、精彩時刻、組隊投票全記錄、戰報海報
- 互動規則頁：概覽 / 陣營 / 誰知道誰 / 一輪點行 / 任務 / 勝負 / 思路 / 擴展

## 本地運行

```bash
npm install
npm start          # http://localhost:3000
npm test           # 先啟動伺服器；用 socket 客戶端模擬多人完整對局（可用 URL=... 指定）
```

技術：Node.js + Express + Socket.IO。進行中的房間存於記憶體（重新部署會清空）。帳號、歷史、統計與頭像相片存於 Postgres（`DATABASE_URL`）；沒有資料庫時回退到 `data/db.json`。
